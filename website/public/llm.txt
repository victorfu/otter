# Otter

Official website: https://victorfu.github.io/otter/
Project repository: https://github.com/victorfu/otter

Otter is speech-to-text for clinical work: dictation and transcription that run on your own computer.

Key pages:
- Home: https://victorfu.github.io/otter/
- Documentation: https://victorfu.github.io/otter/docs
- Privacy Policy: https://victorfu.github.io/otter/docs/PRIVACY_POLICY.md

Key capabilities:
- Expected words: list drug names, procedures and names, and transcription follows them (Whisper models)
- Dictation into any app with a shortcut
- Recording and file transcription with speaker labels
- Transcription runs on the device
- Works on Windows, macOS, and Linux
